# Security

Report SDK security issues privately to [support@sanctionskit.com](mailto:support@sanctionskit.com). Include the affected version, reproduction steps, and expected impact. Do not include API keys or real screening subjects.

Keep keys on your server and grant only the scopes your integration needs. If a key is exposed, revoke it in [API keys](https://www.sanctionskit.com/dashboard/keys) and create a replacement.

See [authentication](https://www.sanctionskit.com/docs/authentication) and [SanctionsKit security](https://www.sanctionskit.com/security) for service guidance.
